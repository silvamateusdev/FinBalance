# Finanças 50/30/20 💰

Aplicativo PWA para gerenciamento de finanças pessoais usando o método 50/30/20.

## 📋 Sobre o Método 50/30/20

O método 50/30/20 é uma regra simples de organização financeira que divide sua renda líquida em três categorias:

### 🏠 50% - Necessidades
Gastos essenciais para sua sobrevivência e qualidade de vida básica:
- Aluguel/Financiamento
- Condomínio
- Contas (água, luz, gás, internet)
- Supermercado
- Transporte (combustível, passe)
- Plano de saúde
- Medicamentos

### 🎉 30% - Desejos
Gastos que melhoram sua qualidade de vida mas não são essenciais:
- Jantares fora
- Streaming (Netflix, Spotify, etc)
- Academia
- Roupas e acessórios
- Viagens
- Hobbies
- Presentes
- Cuidados pessoais

### 💎 20% - Futuro/Dívidas
Investimento no seu futuro financeiro:
- Reserva de emergência (meta: 6 meses de custo de vida)
- Investimentos (aposentadoria, imóvel, carro)
- Quitação de dívidas

**Dica importante:** Pague-se primeiro! Separe esses 20% assim que receber seu salário.

## 🚀 Funcionalidades

- ✅ Configuração de renda líquida mensal
- ✅ Cadastro de despesas por categoria
- ✅ Visualização em tempo real da distribuição 50/30/20
- ✅ Alertas quando ultrapassar os limites de cada categoria
- ✅ Relatório detalhado com recomendações
- ✅ Armazenamento local (LocalStorage)
- ✅ Design moderno e responsivo
- ✅ PWA - Funciona offline

## 🛠️ Tecnologias

- **Vue 3** com Composition API e TypeScript
- **Quasar Framework** para UI/UX
- **Vite** para build
- **LocalStorage** para persistência de dados
- **PWA** com Service Worker

## 📦 Instalação

```bash
# Instalar dependências
npm install

# Executar em modo desenvolvimento
npm run dev

# Build para produção
npm run build

# Build PWA
npm run build:pwa
```

## 🎯 Como Usar

1. **Configure sua Renda**: Na página inicial, informe sua renda líquida mensal (o valor que realmente cai na sua conta)

2. **Adicione Despesas**: Vá até a aba "Despesas" e cadastre seus gastos selecionando a categoria correta

3. **Acompanhe**: Volte para o início e veja em tempo real como está sua distribuição financeira

4. **Analise**: Na aba "Relatório" você encontra uma análise detalhada com alertas e recomendações

## 📱 PWA

Este aplicativo pode ser instalado em seu dispositivo móvel ou desktop:

1. Acesse o aplicativo pelo navegador
2. Procure pela opção "Adicionar à tela inicial" ou "Instalar aplicativo"
3. Pronto! Agora você tem acesso rápido e pode usar offline
